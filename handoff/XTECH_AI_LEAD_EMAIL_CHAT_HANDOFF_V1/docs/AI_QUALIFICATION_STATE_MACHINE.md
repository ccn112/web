# AI Qualification State Machine

NEW → AI_QUALIFYING → NEED_MORE_INFORMATION → AI_RECOMMENDATION_SENT → WAITING_CUSTOMER → HUMAN_READY → ASSIGNED → CONTACTED → MEETING_BOOKED → PROPOSAL

Nhánh khác:
- WAITING_CUSTOMER → NURTURE
- ANY → UNSUBSCRIBED
- ANY → CLOSED_LOST

AI thu thập dần:
1. Bài toán ưu tiên
2. Mô hình doanh nghiệp
3. Quy mô người dùng
4. Hệ thống hiện hữu
5. Phòng ban liên quan
6. Mức độ cấp thiết
7. Thời gian triển khai
8. Hạ tầng
9. Demo/báo giá
10. Người quyết định

Chuyển người thật ngay khi:
- yêu cầu gọi/demo/báo giá;
- yêu cầu phức tạp;
- AI không chắc chắn;
- score đạt ngưỡng;
- khách không muốn tiếp tục với AI.
